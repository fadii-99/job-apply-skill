# Company websites: Greenhouse, Lever, Ashby and others (may be outdated; always read the page)

- Reached from the "Apply" button of a LinkedIn job (not Easy Apply). URLs usually contain greenhouse.io / boards.greenhouse.io, jobs.lever.co, or jobs.ashbyhq.com, but many companies embed them on their own domain.
- One page form: name, email, phone, location, resume upload, LinkedIn/GitHub/website, cover letter (file or text box), then custom questions and sometimes demographic questions.
- Greenhouse: "Attach" for resume and cover letter; "Enter manually" exists for the cover letter text. Some forms parse the uploaded resume and pre-fill fields; read and correct them.
- Lever: "Submit application" at the bottom; "Additional information" is a free text box (field_long).
- Ashby: may auto-fill from the resume upload; read every value back.
- Demographic sections are voluntary: use saved answers, else "Decline to self-identify" / "Prefer not to say".
- Confirmation is usually a "Thank you for applying" page or message.
- Workable, SmartRecruiters, BambooHR, Recruitee and companies' own forms work the same way: read the page, fill from the profile, read back.
- Workday, Taleo, iCIMS and any site that wants a new account, or a sign-in the user's Chrome doesn't already have → ask the user for help (they sign in or make the account themselves, then type "go"), or the manual list when `ask_for_help` is off. Never create one, never type a password. If Chrome is already signed in there, carry on.
